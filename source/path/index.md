> 这个博客里的 40+ 篇文章，不是随手记的笔记，而是一条完整的**测试工程师成长路径**。
> 下面按「先学什么、后学什么」排好顺序，你可以从头往下走，也可以挑自己缺的那块补。

---

## 🗺️ 全景图

```
第 0 阶段  测试基本功        ── 用例怎么设计，BUG 怎么提
    ↓
第 1 阶段  接口测试实战      ── 从 HTTP 到私有协议逆向  ★ 含金量最高
    ↓
第 2 阶段  数据能力（MySQL） ── 会查库才能定位问题
    ↓
第 3 阶段  性能测试（JMeter）── 从"能跑"到"扛得住"
    ↓
第 4 阶段  服务器排查（Linux）── 出问题时你得上得去
    ↓
第 5 阶段  自动化与工具      ── 把重复劳动交出去
    ↓
贯穿始终   面试与复盘        ── 把做过的事讲清楚
```

**如果你是新手**：从第 0 阶段开始，按顺序走。
**如果你是转岗/跳槽**：直接看第 1 阶段，接口测试是最好证明能力的方向。
**如果你在带团队**：第 0、1、5 阶段最值得让组员过一遍。

## 第 0 阶段 · 测试基本功

| [第2课：BUG 管理与缺陷生命周期](/2026/06/12/testing-basics-chapter2-bug-management/) | 优先级怎么定、偶现 BUG 怎么提 |
| [第4课：用例设计方法](/2026/06/15/testing-basics-chapter4-case-design/) | 等价类 / 边界值 / 因果图 / 错误推测 / 白盒覆盖 |

## 第 1 阶段 · 接口测试实战 ★

**目标**：能独立搭一套接口自动化工程，遇到没有文档的私有协议也能自己啃下来。

| 文章 | 讲什么 |
|---|---|
| [学习地图](/2026/09/23/api-testing-00-study-map/) | 整个系列的路线与前置知识 |
| [第1课：入门认知](/2026/09/24/api-testing-chapter1-getting-started/) | **HTTP 200 ≠ 用例通过**、五大测试维度、幂等性 |
| [第2课：脚本骨架与断言设计](/2026/09/25/api-testing-chapter2-script/) | 四块骨架、用例隔离、`dig()`/`check()` 断言设计 |
| [第3课：从客户端日志逆推私有协议](/2026/09/28/api-testing-chapter3-protocol-reverse/) | **旗舰篇** —— protobuf 逆向、0x0A 陷阱、499 不是限流 |

**为什么这阶段含金量最高**：
大部分测试还停留在"点界面 + 报 BUG"。能读懂协议、能搭框架、能定位到具体字段问题的人，在整个团队里是稀缺的。第 3 课那个案例 —— **从日志逆推出一个没有文档的 protobuf 私有协议，并写出 36 条用例** —— 这种能力比会用一个工具值钱得多。

## 第 4 阶段 · 服务器排查（Linux）

**目标**：服务出问题时，你能自己上服务器看明白发生了什么。

| 文章 | 讲什么 |
|---|---|
| [Linux 导读](/2026/06/12/linux-intro/) | 三条救命命令 |
| [第2章：性能监控](/2026/07/20/linux-chapter2-monitoring/) | top / df / free 三件套 |
| [第3章：网络与定时任务](/2026/07/24/linux-chapter3-network-cron/) | ping 通 ≠ 服务可用、CLOSE_WAIT 是代码 BUG |
| [第4章：管道与日志分析](/2026/07/30/linux-chapter4-pipe-log/) | grep → awk → sort → uniq → sort -rn 组合拳 |

**核心认知**：`load` 要跟 CPU 核数比才有意义；`%wa` 高是磁盘瓶颈；`free` 显示内存小不一定是问题（要看 available）。
