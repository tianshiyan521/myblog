## Selenium 专栏介绍

Selenium 是 Web 端自动化测试的事实标准，支持 Python/Java/JS 等多语言，是自动化测试工程师的基础技能。

本专栏以 Python + Selenium 为主线，从零到一搭建 Web 自动化体系。

### 你将学到

<!-- more -->

- **环境速建**：Python + Selenium + WebDriver 配置
- **核心操作**：元素定位（8种方式）、等待机制、窗口/弹窗处理
- **Page Object Model**：为什么需要 POM、如何落地
- **数据驱动**：Excel/YAML 参数化测试
- **报告输出**：pytest + Allure 生成可视化报告
- **持续集成**：Jenkins/GitHub Actions 跑自动化
